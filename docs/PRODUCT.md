# Java Quest 产品与教学设计 · 阶段 0

此页保留原始产品设计。当前课程层级、全部小标题与逐题开放状态以 [完整课程目录](COURSE-ROADMAP.md) 为准；目录覆盖不代表所有课程和运行器已交付。

## 产品目标
以「理解一个概念 → 修改代码 → 真实运行 → 阅读反馈 → 修正 → 通关」取代被动看课。主要用户是第一次学习 Java 的中文学习者。首版每关 5–15 分钟；先建立可独立完成的学习闭环，再扩充技术范围。代码运行结果与课程判定分开显示，提交成功不等于通关。

## 页面与信息架构
- 首页 `/`：继续学习、真实进度、基础路线、推荐下一关、后续六阶段路线。未登录用户看到开始入口，登录后读取服务器统计。
- 课程地图 `/map`：章节、知识点、状态与 XP；必须通过上一关才能提交下一关，允许提前阅读。进度以服务器为准。
- 学习 `/learn/:id`：左侧可折叠导航、中间教学/任务/分级提示、右侧 Monaco 多文件编辑器、运行与测试结果。移动端竖排；不依赖 hover。可保存草稿、添加文件、切换文件、重置；运行中禁重复提交；失败保留代码。成功面板只在真实通过后出现。
- 个人中心 `/profile`：账户、服务器记录的通过数、XP、提交数与时间、按首次通关解锁成就。学习时长暂不采集，不能把在线时间当有效学习时间。
- 错题与笔记 `/review`：真实失败提交与私人笔记；支持回到关卡复习。后续扩展间隔复习，不自动伪造错误解释。
- 项目挑战 `/projects`：展示未来综合项目和验收条件，清晰标记尚未开放。
- 登录/注册 `/login`：可切换模式、错误反馈、密码规则。所有进度和笔记绑定账户。

## 视觉与交互规范
暖白背景 #f7f8f5、深墨文本、绿色主色，系统字体与等宽代码字体。使用 12–24px 卡片圆角、细边框、低强度阴影与 8px 间距体系。支持浅色/深色，初次遵循系统偏好，之后保留选择。布局最大宽度 1440px；学习页优先编辑空间。动画约 180ms，尊重 prefers-reduced-motion。按钮有明确 loading/disabled/focus 状态；异步错误可读、可重试；状态通过 aria-live 播报。庆祝仅在判题通过后短暂显示，不阻止继续操作。

## 六阶段课程路线
1. Java 基础：Hello World、变量、类型、运算、条件、循环、数组、方法、字符串、异常；后续补充类/对象/继承/多态。
2. 集合与数据结构：ArrayList/LinkedList、Map/Set、栈队列、树图、哈希与算法；先预测再播放插入/删除/查找/遍历，动画状态从操作模型产生。
3. Maven：pom、依赖、生命周期、插件、冲突、多模块、打包。多文件任务；先 XML 安全解析和语义断言，再在受控依赖仓库、无凭据的隔离构建容器执行 Maven，禁止任意插件访问主机。
4. Spring Boot：IoC/DI/Bean、Controller/Service/Repository、REST、校验、配置、事务、异常、日志、测试。临时数据库与应用在独立网络沙盒，外部判题驱动 HTTP 合约测试；启动超时与端口限制。
5. 并发：Thread/Runnable、锁/volatile/线程池/Future/CompletableFuture/阻塞队列/死锁。可视化教学使用确定性事件模型；真实练习依赖 latch/barrier 和不变量断言，不以随机调度或固定 sleep 判对错。
6. 企业实战：MySQL、Quartz、WebSocket、统计 API、并发任务队列、综合项目。按 API、迁移、事务、一致性、性能预算分项验收。

题型设计：选择题、补全、修 Bug、预测输出、独立编码、Maven 配置、API 实验、数据结构与并发推演、综合项目。首版仅实现 Java 输出判题，不将输出匹配宣传为源码语义验证。后续增加编译期结构检查与隐藏单元测试。

## 第一关教学脚本
目标：理解 main 入口、字符串双引号与 println。起始程序输出 Hello, learner!，任务改为精确输出 Hello, Java Quest!。知识分三步：入口、输出、分号；三级提示分别指出修改位置、字符串写法、完整语句。判题展示实际 stdout、stderr、预期输出、编译/运行错误、超时或资源限制；空代码、原样代码、错拼写都不能通关。首次通过 +30 XP，重复通过不重复加分。

## 阶段计划与交付门槛
- 阶段 0（本次）：产品/架构/数据库/API/安全边界文档。验收：实现与设计差异可追踪。
- 阶段 1（本次）：Vue 页面、10 个基础关卡、注册登录、MySQL 持久化、独立 Java 容器判题、草稿和笔记、Windows 启动文档。验收：第一关错误/编译失败/通过/下一关/刷新/重新登录均真实联调；后端、前端构建和必要自动测试；不依赖模拟 API。
- 阶段 2（需确认）：课程引擎题型化、数据结构动画、Maven 多文件、Spring API 沙盒、并发事件回放。每一题型交付一个可测试样例及资源预算。
- 阶段 3（需确认）：复习计划、成就体系、全文检索、有效学习事件、管理端与版本化课程发布；迁移向后兼容。
- 阶段 4（需确认）：生产威胁建模、微虚拟机或 gVisor、队列和分布式限流、TLS、备份恢复、指标与告警、供应链扫描、负载与安全测试。

每阶段报告完成/测试/限制，等待确认再进入下一阶段。生产公开多租户上线前必须完成阶段 4；普通 Docker 与宿主共享内核，首版定位为受控本地开发版本。
