## 2026-10-26 更新：可切换的本地进程 / Docker 真实判题

根据用户对公司电脑的限制，新增显式受信任 process 模式。它不是安全隔离；代码拥有当前系统用户的文件和网络权限。默认仍为 off，Docker 模式故障不会自动降级。两个执行器由独立的 Java 判题 jar 协调，学习者代码不在 Spring API JVM 中执行；运行时无需 Python。旧 Python Docker 协调器保留兼容。

本次实际验证（Linux）：

- Maven verify：**14 项通过，0 失败/跳过**。原 API/事务和 off 模式 9 项，加独立进程执行器 5 项。后者真实启动 javac/java，验证显式信任选项、非法路径、多文件/两组 stdin、错误输出、编译错误、运行异常、无限循环超时、输出限制及环境过滤；测试父进程注入了非敏感 marker 变量来验证过滤。
- 可运行 API/judge 两个 jar 已实际启动。独立进程服务的真实 Hello World 通过；缺少认证返回 401，模式不匹配返回 409；Docker 镜像故意不存在时服务退出，没有回退到本地进程。
- Java Docker 执行器真实编译/运行，返回编译错误和无限循环超时；新容器内检查 UID=65534、无外部网卡、根文件系统不可写、未收到 API/判题凭据。另跑多文件/两组输入与 UTF-8 源码，全部通过。源码通过受控 tar 流写入 tmpfs，保留只读根文件系统。验证后无遗留 jq-java-* 容器。
