# Java Quest 完整课程目录与开放状态

当前目录：6 阶段、28 章节、106 知识点、318 个练习标题。其中 42 个已开放，276 个规划中。标题覆盖不等于教学和运行器已经实现。

每个知识点依次安排「模仿/补全 → 定位/修复 → 独立实现或项目验收」。初学固定输出题用于建立语法反馈；后续题使用不同输入和边界案例，项目题保护调用方并编译整套文件。输出判题仍不能完全验证源码是否采用指定技巧，不提供防作弊承诺。

课程目录来自 `backend/src/main/resources/curriculum.json`；已开放教学与测试来自 `lessons.json`。运行 `python scripts/render-course-plan.py` 可重新生成此文件。

## 工程项目递进规范

每个工程系列采用：读调用链与契约 → 修改单个职责 → 修复跨文件缺陷 → 实现需求 → 验证边界/失败 → 工程评审。每个步骤给出与前一步正确结果衔接的独立 starter，草稿按步骤隔离保存；不把上一关用户提交隐式复制为正确代码。

当前订单项目实际开放 3 步、4 个 package 源文件，用 javac 真实编译整套源码：商品行小计 → 折扣服务 → 校验与报表。Application 是只读调用方，服务端拒绝修改它。

后续 Maven 项目需要受控依赖仓库、冻结工具链、构建产物与 JUnit 断言；Spring 项目需要临时应用/数据库和真实 HTTP 合约验证；并发项目需要确定性同步与不变量测试，不能依赖睡眠或随机执行顺序。上述运行器未实现之前，目录保持规划状态。

高级工程能力通过架构决策、数据一致性、性能预算、故障恢复与交付证据验收，不能仅凭刷题数量或 XP 认定。
